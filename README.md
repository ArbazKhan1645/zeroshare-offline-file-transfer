## ⚡ What is ZeroShare?

**ZeroShare** is a high-speed **offline file transfer app** built with Flutter that allows users to share files directly between nearby devices without using the internet.

✔ No internet required
✔ No cloud / no server
✔ Direct device-to-device transfer
✔ Works over WiFi / LAN
✔ Fast, secure, lightweight

---

## 🎯 Features

* 📡 Peer-to-peer file sharing (P2P)
* ⚡ Ultra-fast transfer over local network
* 🔍 Auto-discovery of nearby devices
* 🔐 Secure communication (local only)
* 📱 Cross-platform (Flutter based)

## 🧠 How It Works

ZeroShare uses **local network communication** to connect devices:

1. Devices connect to same WiFi / LAN
2. App discovers nearby peers
3. Files are transferred directly (no internet involved)

## 🚀 Getting Started

```bash
git clone https://github.com/ArbazKhan1645/zeroshare-offline-file-transfer.git
```

### 📦 Install Dependencies

```bash

```

### ▶️ Run App

